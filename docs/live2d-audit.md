提示语分三处：`waifu-tips.json` 的页面/时间文案、控制脚本里的换装/截图/关闭等短句、模型 index.json 内的角色台词。只替换提示语 JSON 不会改变全部台词。

当前取得的通用提示语没有发现原 Hugo 作者的明确邮箱、收款账号或个人域名；但有打赏引导、收款入口描述、站主口吻，以及文章许可、评论免审核、验证码等预设。它们不一定符合本站设置，不宜直接照搬。许多菜单及评论选择器也来自其他主题，需要按本站 DOM 校准。角色名称和角色台词不应直接归类为原博客作者个人资料。

建议保留时间问候、节日、返回页面和常用按钮提示；将站主相关措辞改为 ShadowSky 语境，删除与本站实际功能不符的断言。提示内容当前通过 innerHTML 展示，接入自己的动态文字时需明确文本转义与允许的标记范围。

## 适配层待处理项

以下为源码检查结论，本次没有修改或构建开关测试变体：

1. 模板和 JS 都有 `https://live2d.kafuchino.top/` 默认值，清空 widget 仍会回到该站；cdnPath 为空还会回退到 widget。
2. `live2d-enabled.html` 让单页开关覆盖全局开关；全局 false 加单页 true 会重新启用，与项目宪章约定不符。
3. 空工具列表会恢复默认工具；当前不能通过 `tools=[]` 明确表达“没有工具按钮”。
4. 外站脚本没有在本站固定版本，日后内容变化会直接影响行为；小游戏另有显式 latest 地址。
5. `data-loaded=true` 只表示 initWidget 已调用，不能证明模型成功绘制。
