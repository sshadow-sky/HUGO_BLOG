# 周报卡片杂志排版调整

用户已要求直接调整图片方位、内容排版与装饰；保留刚验收的光影交互。此次在当前 best 工作区做可回退的外观调整，不提交、推送或部署。

## 设计

最新一期用横幅封面与叠放的标题纸页，桌面导读单独置于标题右侧。往期用双列：一类上图下文，另一类左文右竖图，底部保留清晰日期。用真实期号水印、角标、细分隔线表达周刊感，不添加虚构内容或随机数据。相较仅左右镜像，这两类卡片有更清晰差异；相较瀑布流，规则网格更便于按时间浏览。

手机统一单列上图下文，宽屏触控也不启用倾斜/滚动入场；主题色和减少动态偏好继续遵循上一轮实现。摘要、导读、标签、日期、阅读链接来自原数据，无封面显示原占位，不增加外部资源。
