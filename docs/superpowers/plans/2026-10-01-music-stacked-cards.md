# 音乐同尺寸叠卡与点击书签

用户明确纠正前一版：书签只露出小角，不要竖排占满侧边；随心听后面应有一张长宽完全相同的卡片，点击将其抽出，切换书签只切内容；完全取消悬停展开。

## 实施结果

- [x] 三个彩色标签横向排列于顶边，露出约 25px，移除原竖排燕尾书签。原鼠标展开/延迟收起/图钉与自动固定全部移除。
- [x] 背面卡片使用主卡片的实测宽高，初始位置与主卡片完全重叠，层级位于其后。展开平移一个卡片宽度加 12px，保持原尺寸与上下对齐；空间允许时向左，左停靠时向右。
- [x] 点击选中书签抽出，点击其他书签仅更换内容，再点当前书签或关闭按钮收回。快速反向操作从当前平移位置衔接，Esc 优先收回卡片。
- [x] 手机/窄屏在同尺寸原区域展示背面内容，临时隐藏并禁用前卡交互，收回恢复。减少动画偏好直接切换，顶栏书签的高度计入视口定位余量。
- [x] 更新使用说明与宪章，本地保存，不推送或部署。

## 验证

- Hugo 生产构建：30 页面、665 静态文件，成功；音乐与歌词 18 项测试通过。
- 真实浏览器测量：主卡片及背卡均 360×260；动画开始时 x=1036、y=666 完全重叠，前卡遮挡背卡；结束时背卡 x=664、y=666，水平间隔 12px。
- 标签栏横向宽约 208px、高 29px，位于前卡顶部 -25px；鼠标移入等待后仍不展开。标签点击、只切内容无新动画、再次点击收回、快速反向切换、Esc 收回均通过。
- 手机主卡片和背卡均 340×260，位置一致，前卡 inert 正确恢复；百首队列内部滚动，无横向溢出。左停靠向右抽出、减少动画和浅深色截图均验证，未捕获 JS 异常为零。
- 浏览器验收在独立测试资料目录执行，测试队列没有写入用户浏览器。截图、测量和脚本位于 `D:\new_blog\.runtime\music-stack`。
