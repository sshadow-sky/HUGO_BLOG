## 配置与验证记录

开发覆盖文件关闭 `enable`，浏览器另防止 localhost/回环 IP 上报。关闭后页脚位置仍保留“—”。启用状态每次页面挂载向第三方发送一次真实当前 URL，不把本地地址替换为正式域名。

- `node --test tests/statistics.test.mjs`：4 项通过，包含显式关闭、本地地址、空端点、有效数字/服务错误文字过滤、HTTP/网络/空响应失败，以及导航后取消请求与丢弃旧响应。
- 生产 `npm run build`：30 页面、665 静态文件；HTML 启用统计、HTTPS 接口正确、旧 CDN 脚本已移除。
