- 展示站点名称/域名/介绍/副标题、作者昵称/头像路径/状态、首页标题/格言/一言开关、社交和RSS、公告、页脚年份及备案原文。

## 为什么本步先只读

现有TOML同时含身份、主题及服务配置。实测TOML.parse→stringify会丢失文件原有注释（只在内存测试，未写文件）。下步编辑应限定字段、保留原文及未知配置、使用版本保护；不能直接整文件重写。
