## 写回方式与保护

- 只接收sha和changes，changes只允许四个键；名称/昵称非空，副标题/简介可留空，类型/长度/控制字符有校验。
- 固定hugo.toml，站长及仓库/分支鉴权后获取写token；同源POST、先比较当前SHA，再将该SHA交给GitHub Contents更新。并发更新返回409，绝不自动覆盖新版本。通用文件写接口仍不开放整份配置。
- 服务端用原文单行字符串赋值作为候选；逐次替换后完整解析TOML，与仅改目标值的期望树深比较，恰好一个候选符合才接受。注释、空格、CRLF、其他字段/数组/日期及未知数据字节保留；无法定位、缺失字段、多行/点号等未支持写法拒绝422，不降级整文件重写。
- 编辑中刷新禁用；保存中输入禁用；错误保留输入，401新标签登录后手动重试，409提示备份后重新读取，刷新与保存共享429冷却。撤销修改需确认，撤销及编辑器重挂载不解除冷却。
- beforeunload提示离页；未实现持久化草稿或完整站内导航拦截。离开前应保存或复制备份。
- 保存成功返回对应资料和commit/blob版本，更新本页只读卡片；保存仅写GitHub，不部署。没有把后续社交/公告编辑一起开放。
