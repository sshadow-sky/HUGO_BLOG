# ShadowSky 后台需求与范围

本文件描述拟开发的个人后台。首版使用者仅为站长 `sshadow-sky`，多人协作只保留扩展边界。状态为需求草案，功能尚未实现；实施顺序见[开发计划](../superpowers/plans/2026-10-01-admin-development-plan.md)。

## 使用目标

站长可以通过浏览器整理内容、编辑文章与图片、查看真实 Hugo 预览，并明确知道内容是否已保存、是否已经上线。后台还应汇总流量、评论入口和更新任务状态，减少在 GitHub、配置文件和各服务间来回查找。

公开博客继续是 Hugo 静态网站；后台需要独立运行环境，但后台暂时不可用不应影响已经发布的博客。

## 功能分类

| 编号 | 模块 | 首次交付内容 | 扩展范围 | 阶段 |
| --- | --- | --- | --- | --- |
| R01 | 登录与权限 | 仅本人 GitHub 登录、服务端准入、固定本站仓库 | 编辑者/管理员角色与操作授权 | A0–A1 |
| R02 | 文章整理 | 列表、搜索、日期排序、分类/标签和草稿筛选 | 批量修改、分类合并、引用检查 | A1 |
| R03 | 文章编辑 | 元数据表单、Markdown 编辑、图片插入、草稿保存 | 复杂正文的可视化编辑能力逐项验证后开放 | A1 |
| R04 | 媒体库 | 图片上传、选择、插入、替代文字 | 引用位置、孤立资源提示、外部对象存储 | A1 |
| R05 | 本站内容类型 | 画廊文章、画板附件、动态、关于页、友链表单 | 画板在线绘制、相册编辑 | A2 |
| R06 | 站点资料 | 只读检查站名、简介、社交入口等，逐项开放安全编辑 | 导航与展示参数管理 | A2 |

| R08 | 站点概览 | 文章/草稿数、最近修改、最近构建和发布状态 | 个性化概览布局 | A4 |
| R09 | 流量监控 | 接入有证据支持的第三方只读数据及更新时间 | 趋势、来源、热门页面等按数据源能力开放 | A4 |
| R10 | 评论管理 | Twikoo 管理入口和可用性信息 | 通过正式受支持接口内嵌审核/删除 | A4 |

“流量”在本计划中首先指网站访问量 PV/UV；服务器带宽、CPU、磁盘占用属于另一类监控，不能从前端访问统计推导。

## 建议导航与使用流程

侧栏按“概览、文章、动态、媒体、友链、站点资料、发布记录、访问统计、评论、更新任务”组织。尚未接通的模块显示清楚的状态说明，不放置看起来像真实数据的演示图表。

写文章的流程为：新建 → 选择类型 → 填写标题与正文 → 保存草稿 → Hugo 预览 → 调整草稿状态 → 明确发布。每一步显示当前版本；保存完成不等于正式发布成功。

文章整理先提供检索与单篇操作。重命名文章时提示可能影响 URL；删除文章时明确目标并保留 Git 恢复路径。首版不提供一键批量删除文章或媒体，避免在引用关系尚未检查时误删共享资源。

## 文章格式要求

- 普通文章支持现有 Markdown 文本、标题、列表、链接、引用、代码块、表格、图片等结构。
- 对数学公式、Hugo 短代码、内嵌 HTML 及其他主题扩展，要求保存前后语义不变；CMS 编辑器内预览不作为最终渲染依据。
- 始终保留源码编辑通道。不能安全处理的结构显示提示并转为源码编辑，不自动删掉或转义原文。
- 画廊文章与独立相册分开；画板正文与 `.excalidraw` 附件分开。详见[内容映射](03-content-model.md)。

## 首版权限与操作记录

只实现站长账号，不建设邀请、注册、复杂角色配置界面。后端集中判断“读取内容、写入内容、触发预览、发布、修改设置”等操作，为未来角色分配留下入口。

扩展操作记录包含操作者、操作类型、时间、对象路径、提交 SHA、任务结果；不记录凭据、评论密码或完整个人通信内容。文章保存历史优先复用 Git，不另造一份文章数据库。

## 体验与可靠性

- 桌面写作优先，窄屏能查看列表、编辑基本信息和检查任务状态。
- 使用 ShadowSky 青蓝紫配色与克制的阴影动效；表单、阅读与正文输入保持清晰稳定，尊重减少动画偏好。
- 未保存退出、文件冲突、网络中断与会话过期均有明确反馈；失败不显示“已保存”。
- 统计、评论或音乐接口不可用，不影响文章编辑。过期数据保留更新时间，不冒充实时结果。
- 后台不暴露公开注册；GitHub App 私钥、数据库连接及服务凭据只留在后台服务端。

## 本轮不扩大处理的内容

相册保留现状；桌宠整体仍搁置；不迁移 Astro；不恢复旧歌单或原作者订阅源。访客音乐播放队列属于各自浏览器，不属于站长可统一管理的站点歌单，也不规划收集访客搜歌历史。

正式统计验收继续遵循[部署后清单](../post-deployment-todo.md)。本计划提出后台统计能力，不代表已经批准更换统计服务、购买服务或部署服务器。

## 首版完成的判断

内容管理首版以 R01–R04 的完整使用闭环为准：本人可登录、查找文章、编辑含图片和公式的草稿、可靠保存，其他账号不能访问；无需等待统计服务开放接口。

完整后台按 A2–A5 继续交付。流量数据源未具备时，相关项保持“待接入”，不能仅凭展示了空卡片就宣布流量监控完成。
