# A2.5 友链与 RSS 管理验收

2026-10-02，本步本地实现完成。入口：http://localhost:3000/sshadow-sky/hugo_blog/best/file/links 。只供既有站长身份和 best 分支使用。

## 已实现

- 固定 data/links.yaml 文件：页头标题/封面、友链分组与卡片表单、昵称/网站/网址/简介/头像/RSS，展开高级设置编辑颜色/截图/末尾固定；分组布局、默认和分组随机排列。图片库选择头像或封面。保留现有空友链，不恢复样例。
- 分组与友链上下移动；移除可立即撤销一次，后续编辑后撤销入口失效，避免覆盖后来的输入。移除分组同时移除其中友链；媒体文件不删除。
- 第一组标记 RSS 来源，显示其订阅地址。保存不抓取 RSS，不新增后台抓取按钮或定时任务，保留手动 npm run update:links。源变更不会立即改变旧缓存。
- 使用 YAML 文档节点修改和重排，未知元数据及未删除节点注释随节点保留，显式 false 不被吞掉。后端校验完整提交文档而非独立锁定未知字段；站长通过正常表单编辑时保留它们。损坏 YAML/结构或别名文档拒绝编辑，须先修复原文件，不自动清空。
- 精确路径、已有文件 SHA、类型/URL/颜色校验；禁新建/删除/改名。沿用 A1 登录失败、重试、冲突及未保存输入保护。
- 固定 data 文件 SHA 和提交，预览定位既有 /links/ 页面。Hugo links 模板读取 data 标题和封面，缺省回退原页面；空封面明确关闭。
- RSS 手动脚本改结构化 YAML 解析，修复字段顺序变化漏掉来源的问题；首组为空不会读第二组。yaml 2.8.3 精确依赖，npm/pnpm 锁文件同步。

## 使用与剩余边界

1. 在后台添加分组和朋友，首组填写公开 RSS 地址；保存写 GitHub，部署仍独立进行。
2. 本步未真实覆盖远端友链，未推送代码或部署；相册、原保留测试草稿和 8 素材、当前 RSS 缓存不变。
3. 当前远端主题尚未包含本次页头适配，固定提交预览忠实使用远端主题；在主题同步之前，友链卡片正常按远端数据展示，但新标题/封面可能仍是旧值。本地主题已验证支持；没有偷偷修改预览快照伪装远端版本。旧远端 RSS 脚本也需同步本次解析修复后再用。
4. 手动更新 RSS 前，先把已保存的最新友链数据与本次脚本/依赖同步到执行工作区，再运行 npm run update:links。生成的缓存还需进入后续预览/发布流程，本步没有实现一键后台抓取。
5. 截图空值继续使用原前台 WordPress mshots 服务，UI 明示；填本站截图路径可替代。封面支持现有视频路径，选择器目前选图片。
