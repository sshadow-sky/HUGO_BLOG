# 周报交互卡片

2026-10-03，根据用户要求参考 [参考站周报](https://daily.yybb.us/posts/weekly/) 的杂志式卡片和鼠标交互，优化本站周报列表。保留本站青紫色、期号日期、导读、封面和文章入口，独立实现，不引用参考站脚本或作者个人素材。

## 使用效果

- 最新一期采用圆角大卡片、内嵌封面与导读摘要，卡片空白区域也可点击阅读。
- 往期保留左右交错封面、弧形裁切和日期栏；支持的浏览器中，滚动进入视野时轻微上移并淡入。
- 桌面鼠标移动时卡片最多倾斜 3 度，青紫光斑跟随，移开、滚动、切页后复位；阅读箭头有轻微位移反馈。
- 手机采用纵向布局；触屏和减少动态偏好不启用倾斜。键盘链接有焦点反馈，深浅主题均适配。

## 实现范围

卡片模板新增独立表面层；固定外层提供指针位置基准，避免倾斜导致测量抖动。`weekly-cards.js` 以事件委托覆盖加载更多产生的卡片，使用页面清理机制解除监听。滚动入场使用原生 CSS 能力检测，未支持的浏览器直接显示完整卡片。

未修改文章正文、草稿状态、后台编辑器或服务配置。此次仅完成本地修改，未提交、推送、部署。1314 是包含测试草稿和排版样例的本地预览，不代表正式发布内容。

## 第二轮：独立的周刊排版

用户随后认可交互，要求调整图片方位和内容装饰，拉开与普通文章预览的区别。新版取代上面的左右交错横条排版：

- 最新一期：全幅横图、刊物角标与大期号，封面下缘叠放标题纸页；桌面右侧为编号导读，手机导读移到摘要下面。
- 往期：桌面双列，上图下文与左文右竖图交替；期号淡水印、虚线日期底栏和星形角标。1000px 以下单列，600px 以下两种卡片都改为上图下文。
- 最新卡片改为一个整卡阅读链接，避免重复键盘停靠。原倾斜、光斑、主题和减少动态设置保留；加载更多卡片同步输出期号水印。
- 装饰使用现有封面、真实期号和 CSS；没有增加外部请求或改动文章内容。

新增样式独立在 `themes/aiovtue/assets/css/_weekly-editorial.scss`，由周报样式引入。原普通文章列表不受影响。

用户进一步指定左右排版和中间的波浪蕾丝装饰。本轮仅修改 `_weekly-editorial.scss`，取代第二轮双列和横幅布局：最新一期左图右文，往期单列横向卡片、封面左右交替。期号、水印、日期栏和光影交互保留。

图文边界使用纸色半圆齿边、细波浪、小圆环与点线组成蕾丝。装饰以 CSS 伪元素与内联 SVG 蒙版实现，不下载外部素材，`pointer-events: none` 不影响整卡点击。深色同步纸面色；700px 以下改上图下文，分隔边转为水平。
