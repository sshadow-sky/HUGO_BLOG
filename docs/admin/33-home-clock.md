## 第二步：动态天空与访客天气（2026-10-06）

用户要求美化卡片，并明确选择“定位访客位置，展示访客的实时天气”。本节取代上文关于天气尚未接入的历史状态；地理距离与倒计时仍未添加。

### 实现方向

- 保留右栏位置、数字时钟和时间进度。新增分层天空、日光/月牙、缓慢云层、星点、半透明内容面板，沿用粉色标题与青紫色进度。
- 天气按晴、多云/阴、雨、雪、雾、雷雨区分。雨丝、雪粒和雾层均由 CSS 绘制，没有外部图片；雷雨仅缓慢光晕变化，无频闪。系统“减少动态效果”关闭全部卡片动画，未显示的天气粒子暂停动画。
- 默认仅按设备本地 6:00–18:00 显示昼夜，不请求定位或天气。访客点击“查看当地天气”才触发浏览器定位授权，支持关闭和重试。未授权、不支持定位、超时或服务失败时保持时钟、回退本地昼夜。
- 天气有效时使用服务返回的 `is_day` 切换所在地昼夜；数字时间仍清楚标注浏览器本地时区。天气展示“你附近”，不推测城市名称，不接额外 IP 或逆地理编码服务。

### 数据与生命周期

- 使用 [Open-Meteo 官方 Forecast API](https://open-meteo.com/en/docs) 的 `current=temperature_2m,weather_code,is_day`，Unix 时间戳校验新鲜度。该服务的当前天气来自天气模型，并非本站传感器逐秒观测。
- 端点为 `https://api.open-meteo.com/v1/forecast`；坐标取小数点后两位发送，不发送凭据和 Referer，不写本地存储或本站后台。卡片提供数据来源链接和定位用途提示。
- 免费端点适用于非商业用途，后续若改为商业站点或超过服务限额，按 [服务条款](https://open-meteo.com/en/terms) 调整服务方案；未复制参考站密钥。
- 当前页面开启后每 15 分钟重新定位和查询；隐藏标签页暂停调度，恢复后检查刷新期限。定位超时 10 秒、整体查询上限 25 秒；返回异常、未知天气码或超过 90 分钟的过旧数据，不显示伪造天气。
- 关闭、重复挂载或 PJAX 离页清理定时器/监听，取消请求并忽略迟到回调。位置和启用状态不持久化，刷新或重新进入页面后需再次点击入口；浏览器可以保留用户授予的位置权限。
- 公网使用浏览器定位需要 HTTPS；localhost 可用于本地验证。

### 验证记录

- 全部 23 项测试通过，其中天气 6 项覆盖天气码、昼夜、空值/过旧响应、显式启用、拒绝授权、成功/隐藏恢复/关闭、超时、网络失败、离页和迟到回调。
- 1314 的真实浏览器请求成功：使用测试坐标查询实际 Open-Meteo，返回晴和温度。此验证使用测试位置，不声称已定位到用户本人。
- 其余晴天/夜色/多云/雨/雪/雾/雷雨使用明确的模拟响应逐一检查排版和状态；减少动态效果、拒绝定位回退、未点击不请求通过。深浅主题截图已检查；PJAX 往返后走时及 390px 隐藏/无溢出通过。
