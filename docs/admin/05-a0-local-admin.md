## 需要站长完成的 GitHub 操作

1. 打开 `http://127.0.0.1:8787/start`，使用 `sshadow-sky` 登录 GitHub 并确认创建私人 App。
2. 安装时选择 **Only select repositories → HUGO_BLOG**。
3. 回到 `http://localhost:3000/sign-in`，以站长身份登录。

回调会自动写入本地 App 凭据，无需复制私钥到聊天。向导超时后，可在后台目录运行 `scripts/start-github-setup.ps1` 重新打开。若 GitHub 连接依赖代理，显式传入当前机器使用的代理地址。
