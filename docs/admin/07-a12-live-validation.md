## 验收发现与修复

原编辑器在网络恢复时直接采用后台刷新结果，覆盖未保存输入并推进 SHA。现改为独立跟踪编辑版本：有未保存输入或正在保存时不应用远端快照，刷新失败不卸载已有表单；成功保存只确认对应版本，较晚输入继续保留。

同时忽略封面等控件初始化时重复提交原值的事件，避免刚打开文章就显示已修改。新建文章首次保存期间暂时禁止表单输入，防止保存后的页面跳转丢失后续输入；已有文章保存期间可以继续编辑。
