# A2.1 画廊卡片编辑

2026-10-02，用户授权进入 A2，并选择图片卡片编辑。本小步已完成本地实现与验收，后台入口：[新建画廊](http://localhost:3000/sshadow-sky/hugo_blog/best/collection/posts/new?kind=gallery)。

## 使用方式

文章管理页点击“新建画廊”，填写标题与文章日期，保持默认草稿。从现有文章素材库选择或上传图片，可以一次选多张；卡片直接显示图片/GIF，分别填写替代文字、图片说明，用上下按钮调整顺序。图片说明支持多段文字及常见 Markdown；顺序就是前台轮播顺序。移除卡片只取消引用，不删除素材文件。

卡片/Markdown 源码切换本身不改原文。卡片实际编辑后生成符合现有主题的 Markdown：图片前为介绍，独立图片行后为该图说明。复杂 HTML、短代码、代码、引用式图片或视频等不强制转换，保持源码并提示使用源码编辑。卡片首版上传类型沿用 PNG/JPG/JPEG/WebP/GIF；视频卡片与绘图工具不在本步。

新建时保存 `layout: gallery-post`，新文章仍存 `content/posts/`，默认草稿。保存仅写 GitHub，不代表部署。列表显示“画廊”类型，详情重读按真实 layout 自动进入卡片编辑。日期、简介、封面、分类、标签与普通文章共用，沿用 A1 的冲突、网络、登录恢复及未保存提醒。

## 实现与范围

后台新增 `lib/gallery-content.ts` 和 `components/entry/gallery/`；文章新建页通过 `kind=gallery` 提供独立入口，Entry/EntryForm传递画廊状态。服务器允许新建文章显式提交唯一新增类型 `gallery-post`；既有文章仍保留原文件类型，不从新建参数转换类型。远端 A1 配置不含 layout，因此读取列表、读取详情及新建保存均作了窄范围适配，不修改远端 `.pages.yml` 或放宽目录授权。

图片预览使用已登录的本地素材接口，存储继续使用 `/uploads/` 公共路径。旧站内非 uploads 路径不猜测媒体位置，提示在 Hugo 预览中查看；HTTPS 图片可直接预览。相册 `content/gallery/`、画板、动态、友链与站点配置未改。
