# A2.3 动态管理

2026-10-02，用户确认继续动态管理。本小步已完成本地实现及隔离验收。入口：[动态管理](http://localhost:3000/sshadow-sky/hugo_blog/best/collection/moments)，[新建动态](http://localhost:3000/sshadow-sky/hugo_blog/best/collection/moments/new)。

## 使用

填写管理标题、日期、草稿状态，然后编写动态文字，从文章素材库选择或上传配图。管理标题用于后台查找，现有前台卡片不显示它。卡片编辑可预览PNG/GIF等图片、上下调整顺序、取消引用；取消引用不删除素材。新建默认为草稿，保存仍只写GitHub，网站需后续构建部署。

卡片最多9张配图，与现有前台九宫格上限一致。前台不展示逐图图注，因此本步不提供逐图图注输入。文字支持常用Markdown；复杂HTML/短代码/代码块、图片间文字或超过9张图片的旧正文保留在源码模式，不强制转换或截断。源码入口仍允许原主题支持的内容；9张限制针对卡片编辑，原主题前台最多显示前9张。

动态不同于文章，没有单条详情页。“动态页预览”构建并打开整个栏目，包含当前快照内的草稿；较旧动态仍按前台原有分批加载逻辑显示。没有擅自修改栏目cascade来制造详情页。

## 实现

- 本地能力配置增加moments集合和侧栏，路径content/moments；新建沿用时间bundle/index.md，旧平铺Markdown也可编辑。编辑字段限title/date/draft/body，保留既有未知元信息；新提交不能注入layout或cascade。远端.pages.yml及SHA不变。
- 配图编辑复用现有图片卡片组件，以moment模式调用专用文字/图片转换器。普通画廊的逐图说明和布局继续保留。
- POST/GET/列表沿用Hugo TOML/YAML解析与A1保存保护：SHA冲突、登录/网络/限流恢复、未保存离页提醒。栏目_index.md、跨目录写入、改名和删除不开放。
- 本地预览验证动态文件SHA与提交；在隔离快照的预览索引中把动态映射到所属栏目链接。content/moments/_index.md中的render:never/list:always完整保留。
- 动态工作台提供列表/标题搜索/日期排序/草稿筛选，隐藏此类型未提供的分类、标签控件。
