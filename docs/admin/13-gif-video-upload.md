# 后台 GIF 与视频素材（2026-10-02）

独立后台 HUGO_BLOG_ADMIN 已支持 GIF、MP4、WebM 上传，单文件 20 MiB。素材仍在 static/uploads，文章保存 /uploads 路径。

- GIF 使用正文“图片与图注 → 选择或上传图片”，保留动画；最多 500 帧、单帧 2500 万像素、总解码 1 亿像素。
- MP4/WebM 使用“视频 → 选择或上传视频”，可直接在编辑器播放及拖动。不转码，不接入视频平台观看页面。
- “文章素材”增加全部/图片/视频筛选和视频预览；封面选图仅接受图片。
- 单文件最多 20 MiB、每批最多 10 个，保留顺序队列和原路径重试。

本地 .pages.yml 增加 gif/mp4/webm 并改名文章素材。远端尚未推送，当前后台以仅限本站 uploads 的配置适配启用功能；不改远端配置 SHA。

135 项测试、类型检查、编辑器及素材库浏览器验证、真实 Hugo 主题隔离构建通过。GIF 动画帧变化；MP4、含音轨 WebM、静音 WebM 能播放及拖动。补齐本地 Hugo 预览服务的 Range 支持。真实登录只读现有私有 PNG 的 206/HEAD 和匿名拒绝已验证。

上传与文章保存采用隔离模拟，未向远端新增测试素材或文章，未推送部署。真实 GIF/视频远端写入和上线展示仍待后续验收。独立后台详细记录：docs/superpowers/gif-video-upload-validation.md。
