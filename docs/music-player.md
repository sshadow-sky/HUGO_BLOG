# 搜索式音乐播放器

点击右下角吸边的音乐入口，主卡片显示封面、当前歌曲、进度及播放控制。左侧有搜索、歌词、队列三个书签：鼠标悬浮预览，点击固定；再次点击同一书签关闭。也可使用抽屉顶栏的图钉固定/取消固定，关闭按钮收起。输入框获得焦点后会固定抽屉，避免打字时误收起。键盘可用 Tab 与 Enter 操作；Esc 先关闭栏目，再关闭整个播放器。

选择搜索书签后输入歌名或歌手。输入停止约 450 毫秒后搜索，也可回车或点击搜索按钮。中文输入法组词过程中不搜索。

- 每次显示最多 10 条结果。三角按钮立即播放该曲；加号只加入队列，不打断当前播放。
- 队列按来源与歌曲 ID 去重，最多 100 首。可移除单曲或清空队列；移除当前歌曲会停止播放。
- 提供暂停、进度拖动、音量、上一首/下一首、顺序/随机/单曲模式。顺序播放到队列末尾停止；随机模式的自动切歌和手动上一首/下一首均随机选择其他曲目；单曲模式自动重复当前歌曲，手动切歌仍可选择相邻曲目。
- 普通站内 PJAX 切页保留同一音频实例；完整刷新会停止音频，只恢复队列、当前歌曲信息、音量和模式，需主动点击继续播放。
- 播放失败停留当前歌曲，显示重试/换歌提示；不自动轮询其他第三方服务。
- 桌面主卡片约 360×260px（错误提示可能增高），抽屉宽 320px，书签栏与抽屉跟随主卡片实际高度，上下对齐。长队列与搜索结果各自在抽屉内滚动，数量不会撑宽卡片；栏目标头及操作留在顶部。
- 搜索、歌词、队列分别采用青蓝、紫罗兰和暖橙书签，配有燕尾缺口与对应色的书页边缘。展开约 420ms、收起约 240ms，内容从书签一侧抽出/收回；悬浮预览后点击固定也会播放抽页效果。快速切换会取消旧动画。手机和减少动画模式直接切换栏目。
- 手机和无法容纳双栏的位置改为卡片内栏目，点击切换；短屏时整个面板也可滚动。停靠左侧且有空间时，抽屉自动向右展开。
- 播放时封面柔光呼吸，当前队列歌曲显示装饰性的跳动条；暂停或启用“减少动画”时停止。跳动条表示播放状态，并非音频频谱。音量按钮点击展开滑条。

## 歌词

歌词书签展开时才向已配置服务请求当前歌曲的歌词。带 LRC 时间戳的歌词逐行高亮并居中跟随，拖动播放进度会重新定位。手动滚动歌词会暂停自动跟随，可点击“回到当前句”恢复；切换歌曲后恢复跟随。普通文本歌词静态显示，没有歌词时提示“暂无歌词”，网络失败可点重试。

支持多时间标签、小数秒及 offset；正 offset 使歌词提前显示（参照 [LRC 解析库对 offset 的说明](https://github.com/Clarkkkk/paroles)）。歌词仅在当前页面内存中保留，不写入 localStorage；关闭歌词栏目会取消尚未完成的请求，切歌后旧响应不会覆盖新曲歌词。歌词是否存在和时间轴是否准确取决于来源。

## 配置

`hugo.toml`：

```toml
[params.music]
  enable = true
  position = 'right'
  endpoint = 'https://music-api.gdstudio.xyz/api.php'
  source = 'netease'
```

`endpoint` 需支持 GD 协议的 `types=search/url/pic/lyric` 和相应 JSON 格式，可使用 HTTPS 服务或同源 API；不是任意音乐网页地址。浏览器直连第三方时需要对方允许 CORS。本项目当前使用 GD Studio 的网易云来源。音频与图片 URL 仅接受 HTTPS。

没有默认歌单、账号或自动播放。首次页面加载及空队列打开面板均不请求音乐接口；搜索后请求结果，可见封面按需获取。已有队列在打开面板后可能获取封面，点击播放才解析音频。接口或来源留空会提示未配置，不使用默认代理回退。

全局 `enable=false` 不输出播放器及专用脚本；单页 `musicPlayer:true` 不能覆盖全局关闭。`musicPlayer:false` 可控制该页面直达时的渲染；已创建的全局播放器会跨普通 PJAX 切页保留，支持持续播放。

## 数据保存和隐私

访客队列保存在自己浏览器的 `localStorage`，键名为 `shadowsky-music-v1`；只保存版本号、曲目 ID/标题/歌手/封面 ID 等元数据、当前曲目键、音量及播放模式，不保存音频文件、临时播放地址或登录凭据。清空队列即可删除保存的曲目。存储不可用时仍可在当前页面会话使用。

搜索关键词及曲目 ID 会发送到配置的音乐服务；封面和音频可能来自其返回的其他 HTTPS 域名。没有默认歌单请求，也不再加载 APlayer/Meting 或三个旧解析代理。

## 维护

- `themes/aiovtue/assets/js/music-api.js`：接口参数、超时、数据校验。
- `themes/aiovtue/assets/js/music-controller.js`：队列、搜索/播放竞争、音频事件和本地保存。
- `themes/aiovtue/assets/js/music-view.js`：DOM、输入法、封面按需加载和控制按钮。
- `themes/aiovtue/assets/js/music-drawers.js`：书签悬浮/固定、栏目切换和响应式位置。
- `themes/aiovtue/assets/js/music-lyrics.js` / `music-lyrics-view.js`：歌词解析与请求、逐行跟随与手动滚动。
- `themes/aiovtue/assets/js/music-player.js`：悬浮入口、吸边、位置和开合。

测试：`node --test tests/music-search.test.mjs tests/music-lyrics.test.mjs`。实现与浏览器验证记录见 [搜索播放器](superpowers/plans/2026-09-30-music-search.md) 和 [书签抽屉](superpowers/plans/2026-09-30-music-drawers.md)。第三方服务的返回与播放能力可能变化；本地一次播放成功不代表所有歌曲或以后均可用。
